# Maison de Beauté — Aura Salon

Tek dosyalık (`index.html`) lüks güzellik salonu landing page'i.

**Altyapı:** Tailwind CSS (CDN), GSAP 3 + ScrollTrigger, Lenis smooth scroll, Font Awesome, Google Fonts (Cinzel, Playfair Display, Plus Jakarta Sans).

**Bölümler:** Preloader (split-text + % sayaç) · Cam efektli navbar · Hero (kelime reveal, 3D mouse paralaks, dönen rozet) · Manifesto · Yatay kaydırmalı hizmetler · Paralaks galeri · Ekip · Sonsuz marquee + yorum slider'ı · Randevu formu & footer.

Çalıştırmak için `index.html` dosyasını tarayıcıda açmanız yeterli.
